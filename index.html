Install in a minute

You need Neovim 0.12+ and Git on Linux. Your existing ~/.config/nvim is backed up, never deleted, and nothing needs sudo.

  1. 1Get the tools

    ❯sudo pacman -S --needed neovim git ripgrep fd make gcc
    ❯sudo apt install git ripgrep fd-find make gcc curl

    Distro packages of Neovim are usually older than 0.12 — use the official release tarball (how).

    ❯sudo dnf install neovim git ripgrep fd-find make gcc

    A Nerd Font in your terminal gives you file and folder icons. Not required — WraithVim falls back to plain text.

  2. 2Install WraithVim

    ❯ git clone https://github.com/cachewraith/wraithvim ~/.local/share/wraithvim ~/.local/share/wraithvim/install.sh

    Want to look first? install.sh --dry-run prints every step and changes nothing. To try it next to your current setup: install.sh --appname wvim, then NVIM_APPNAME=wvim nvim.

  3. 3Open it

    ❯nvim

    The first start downloads the pinned plugins (a few seconds). Then run :Health to see what is installed and what is optional.

update

Inside WraithVim press Space u u (or type :Update), then restart. Your settings in ~/.config/wraithvim/ are never touched.

uninstall

~/.local/share/wraithvim/uninstall.sh asks before every step, restores your old config from its backup and keeps your settings.

Your first ten minutes

Coming from VS Code? These are the only things you need. Keys are pressed one after another — Space g g means Space, then g, then g.

  1. The one new idea: two modes

    In Normal mode keys are commands; in Insert mode keys type text. Press i to start typing and Esc to stop. The statusline always shows which mode you are in.

  2. Press Space and wait

    A popup lists every key you can press next. You never have to memorise anything — Space e opens the explorer, Space ? shows them all.

  3. Find anything

    Space Space finds a file by name, Space / searches text in the whole project. Click a file in the explorer to open it.

  4. A terminal at the bottom

    Space t or Ctrl+Shift+` opens it. Click inside to type, Esc Esc to scroll and copy, Hide in its header to tuck it away.

  5. Forgot a key? Search for it

    Space p (or F1) lists every action by name with its key — type pull, graph, format, press Enter.

  6. Git without leaving

    Space g g draws the commit graph, Space g s shows status, Space g c commits. Merge conflicts open in a three-way view.

What's inside

An IDE's worth of tools, loaded only when you use them.

editor

  • File explorer with icons, Git status and single-click open
  • Clickable tabs, dashboard, notifications
  • Fuzzy find files and text (ripgrep, fd)
  • Full mouse support — click, drag, scroll, select
  • Default, compact and minimal layouts

git

  • Commit graph of all branches
  • Change markers, stage & undo hunks, blame
  • Status, commit, amend, push, pull, branches
  • Side-by-side diffs and file history
  • Three-way merge conflicts on Git's index stages

code

  • Native LSP: definition, references, rename, fixes
  • Completion with snippets
  • Format on demand or on save
  • Treesitter highlighting, on demand
  • Nothing installed behind your back (Mason optional)

Make it yours

Your settings live in small files that updates never touch. Mistakes are reported, not fatal.

-- VS Code shortcuts: Ctrl+P, Ctrl+B, Ctrl+`, Ctrl+/, F12 …
return {
  preset = "vscode",
  disable = { "s", "S" },        -- remove keys you don't want
  { "n", "<leader>qq", "<cmd>qa<cr>", desc = "Quit all" },
}
return {
  preset = "default",            -- default | compact | minimal
  theme = { style = "night" },     -- tokyonight: night | storm | moon | day
  icons = { nerd_font = true },
  explorer = { width = 34 },
  terminal = { shell = "fish", height = 14 },
}
return {
  java = false,                    -- turn a language off
  php = { formatters = { pint = false } },
  zig = {                           -- or add your own
    filetypes = { "zig" },
    servers = { zls = { cmd = "zls" } },
  },
}
return {
  format = { on_save = true },
  mason = { enabled = true },        -- optional tool installer, asks first
  opt = { relativenumber = true, wrap = true },
}
